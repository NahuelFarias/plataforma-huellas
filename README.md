# 🐾 Huellas

**Huellas** es una aplicación web diseñada para conectar refugios de rescate de animales con personas interesadas en adoptar, ser voluntarios o contribuir económicamente. Este proyecto busca facilitar el proceso de adopción y brindar transparencia en las colectas para ayudar a los refugios a cumplir su misión.

## 🎯 Propósito del Proyecto

El objetivo de este proyecto es desarrollar una plataforma funcional que permita:

- 📍 **Encontrar refugios cercanas** según zonas predefinidas.
- 🐶 **Explorar mascotas en adopción** de diferentes refugios.
- 💰 **Contribuir a colectas activas** con seguimiento de recaudación en tiempo real.
- 📋 **Permitir a las refugios registrar sus perfiles** con información relevante.
- 🤝 **Facilitar el registro de adopciones y voluntariados** a través de Google Forms integrados.

## 🚀 Funcionalidades Principales

### 🔗 Para Adoptantes:
- Búsqueda de refugios por zona geográfica.
- Visualización de animales en adopción con imágenes y descripciones.
- Donación a colectas activas con integración de MercadoPago.

### 🏢 Para Refugios:
- Registro de perfiles con información de contacto, redes sociales y ubicación.
- Publicación de animales disponibles para adopción.
- Creación y gestión de colectas con objetivos económicos visibles.

### 🔒 Control de Acceso:
- Sistema de beta cerrada con lista de correos preaprobados o aprobación manual.
- Autenticación segura con JWT.
